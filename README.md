# Asset Management

Production-oriented Asset Management backend built with **NestJS**, **TypeScript**, **Node.js**, and **MongoDB**.

The application is being developed with a modular and scalable architecture and follows production-level engineering practices for security, validation, testing, API documentation, file management, email communication, and maintainability.

---

## Technology Stack

### Backend

- NestJS
- TypeScript
- Node.js
- Bun

### Database

- MongoDB
- Mongoose

### API

- REST API
- Swagger / OpenAPI
- Postman

### Development

- Git
- GitHub
- GitHub Codespaces
- VS Code

---

## Project Goals

The application is intended to provide a complete Asset Management system with capabilities such as:

- User management
- Authentication and authorization
- Asset management
- Asset types/categories
- Asset allocation
- Asset requests
- Asset lifecycle management
- File uploads
- Email communication
- Notifications
- Reporting
- API documentation
- Automated testing

The exact business modules and workflows will be defined and implemented incrementally based on the application requirements.

---

## Development Environment

The project is developed using **GitHub Codespaces**.

This allows the backend development environment to run remotely while the local machine primarily requires a web browser and development tools such as Postman.

The Codespace provides:

- Node.js
- Bun
- NestJS CLI
- Git
- VS Code
